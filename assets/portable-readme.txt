WiFi 密码清单 · WifiList v1.6.1（绿色免安装版）
================================================

这是绿色免安装版：解压后双击 WifiList.exe 即可使用。
没有安装程序、不写注册表、不常驻后台、不联网上传数据。

This is the portable build: unzip and run WifiList.exe.
Nothing is installed, no registry keys are written, nothing is uploaded.

นี่คือเวอร์ชันพกพา: แตกไฟล์แล้วเปิด WifiList.exe ได้เลย
ไม่มีการติดตั้ง ไม่เขียนรีจิสทรี และไม่อัปโหลดข้อมูลใด ๆ

功能 / Features / คุณสมบัติ
---------------------------
· 查看本机已保存的 Wi-Fi 名称与密码，支持连接、断开、增删改配置
· 一键导出 HTML 报告（中文 / English / ไทย 三种语言）
· 界面语言可切换：标题带最右侧的地球按钮
· 数据只在本机处理；导出的报告含明文密码，请勿随意外传

· List saved Wi-Fi profiles and their passwords; connect, disconnect, add, edit, delete.
· Export a self-contained HTML report in Chinese, English or Thai.
· Switch the interface language from the globe button in the title bar.
· Everything stays on this PC. Exported reports contain plaintext passwords.

· ดูรายชื่อและรหัสผ่าน Wi-Fi ที่บันทึกไว้ เชื่อมต่อ ตัดการเชื่อมต่อ เพิ่ม แก้ไข ลบ
· ส่งออกรายงาน HTML ได้ในภาษาไทย อังกฤษ และจีน
· สลับภาษาด้วยปุ่มลูกโลกบนแถบชื่อ
· ข้อมูลอยู่บนเครื่องนี้เท่านั้น รายงานที่ส่งออกมีรหัสผ่านแบบข้อความธรรมดา

------------------------------------------
Windows 10 / 11，.NET Framework 4.8（系统自带）。
Windows 10 / 11 with .NET Framework 4.8 (included in the OS).
Windows 10 / 11 พร้อม .NET Framework 4.8 (มีมาในระบบอยู่แล้ว)
